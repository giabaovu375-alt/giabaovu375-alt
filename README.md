## Featured Project

### 🔥 [ViBao](https://github.com/giabaovu375-alt/Vibaoc) — early / unstable

A DSL and compiler for building web UIs using keywords from your own language, not just English. Vietnamese and English are supported today, mix freely — more languages are planned next.

```
button("Tang") {
    khi_nhan {
        $dem = $dem + 1
        neu $dem >= 10 {
            thong_bao("Da dat 10!", kieu: thanh_cong)
        }
    }
}
```

Built with Rust, compiles to a static web app (HTML/CSS/JS + a small WASM runtime). Still version 0.1.0 and actively evolving — the architecture is designed so new language keywords can be added without touching the core compiler.
